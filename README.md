# Nisha Qureshi — Personal Portfolio

A responsive personal portfolio website built with HTML5 and CSS3.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in Google Chrome, or open the folder in VS Code.
3. Edit the content in `index.html` and styling in `style.css`.

## Before publishing
- Add your university/college name and graduation year in the Education section.
- Review the Technical Skills list and remove any skills you do not want to claim.
- Add a live deployment URL for SkillTrack if available.
- Add the public GitHub repository URL for the E-Commerce App if you have one.
- Optional: replace the initials illustration with your own profile photo.

## Publish
Create a GitHub repository, upload `index.html`, `style.css`, and this README, then enable GitHub Pages in the repository's Settings > Pages.
